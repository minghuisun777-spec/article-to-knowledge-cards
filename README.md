# 知识卡片生成 Skill

`make-knowledge-cards` 是一个用于 Codex 的指令型 Skill，可将文章整理成聚焦原文依据的学习卡片。它帮助读者从长文中区分重要知识与辅助细节、合并重复内容，并避免总结时加入原文不支持的说法。

## 项目解决的问题

阅读长文章时，核心概念、论据和限定条件容易被细节淹没；直接摘录又可能重复，或在改写时引入原文没有的信息。本 Skill 按知识点组织文章内容，并要求卡片内容能由原文支持。

## 主要功能

- 接受聊天中粘贴的文章，或本地 Markdown（`.md`）和纯文本（`.txt`）文件。
- 提取重要概念、主张、机制、证据及限定条件，并合并重复信息。
- 原文支持时生成 5～8 张卡片；若独立知识点不足，则少于 5 张，不为凑数重复或拆分内容。
- 每张卡片只讲一个知识点，包含标题、核心知识、简明解释，以及原文例子或可由卡片回答的自测问题。
- 默认保留原文语言，不补充原文没有的事实，并保留不确定性与必要限定。

暂不支持网页抓取、PDF、Anki 和图形界面。

## 安装方法

本项目中的 Skill 源文件位于 `skills/make-knowledge-cards`。若要在 Codex 中使用，请将整个 `make-knowledge-cards` 文件夹复制到个人 Skills 目录：

- Windows 默认目录：`%USERPROFILE%\.codex\skills\make-knowledge-cards`
- 其他平台默认目录：`~/.codex/skills/make-knowledge-cards`
- 若设置了 `CODEX_HOME`，则复制到该目录下的 `skills/make-knowledge-cards`。

在 Windows 上，可从项目根目录运行以下 PowerShell 命令进行首次安装：

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex\skills" | Out-Null
Copy-Item -Recurse ".\skills\make-knowledge-cards" "$env:USERPROFILE\.codex\skills\"
```

若使用自定义 `CODEX_HOME`，请将文件夹复制到该目录下的 `skills` 文件夹。此 Skill 不需要额外运行时依赖、安装脚本或 API 密钥。安装后新建 Codex 对话，即可调用该 Skill。

## 使用方法

输入 `$make-knowledge-cards`，然后粘贴文章，或提供本地 `.md` / `.txt` 文件路径。

粘贴文章：

```text
$make-knowledge-cards
请把这篇文章整理成知识卡片：
[粘贴文章内容]
```

读取本地文件：

```text
$make-knowledge-cards
请读取 C:\Users\me\Documents\article.txt 并生成知识卡片。
```

## 输入与输出示例

**输入文章**

> 反复阅读会让人觉得文章越来越熟悉，但熟悉感本身不能证明学习者能够回忆内容。提取练习要求学习者先尝试从记忆中提取信息，再查看材料。练习后的反馈可以揭示错误并纠正误解。与把同样的练习都放在一次学习中相比，将练习分散到多个学习时段有助于较长期的记忆。合适的练习间隔取决于材料需要保持记忆的时长，因此不存在适用于所有目标的统一安排。简短、低风险的小测验是课程中加入提取练习的一种方式。

**输出**

### 1. 熟悉感不等于能够回忆
- **核心知识：** 反复阅读可能带来熟悉感，但熟悉感本身不能证明学习者能够回忆材料。
- **简明解释：** 看着文本时觉得认识它，与不看文本时从记忆中提取内容，是不同的检验方式。
- **自测问题：** 为什么反复阅读产生的熟悉感不足以证明学习者能够回忆内容？

### 2. 提取练习要求先尝试回忆
- **核心知识：** 提取练习中，学习者先尝试回忆信息，再查看材料。
- **简明解释：** 关键顺序是先从记忆中提取，再核对原材料。
- **自测问题：** 查看材料之前，学习者需要先做什么？

### 3. 练习后的反馈有助于纠错
- **核心知识：** 提取尝试后的反馈可以揭示错误并纠正误解。
- **简明解释：** 反馈让学习者发现回答中的问题，并据此修正理解。
- **自测问题：** 原文指出反馈在提取练习后可以发挥哪两种作用？

### 4. 分散练习有助于较长期记忆
- **核心知识：** 将练习分散到多个时段，相比把相同练习集中在一次学习中，有助于较长期的记忆。
- **简明解释：** 原文比较了多次练习与单次集中练习对长期保持的作用。
- **自测问题：** 原文认为哪种练习安排更有助于较长期的记忆？

### 5. 练习间隔应匹配记忆目标
- **核心知识：** 合适的练习间隔取决于材料需要保持记忆的时长。
- **简明解释：** 不同的记忆目标可能需要不同间隔，因此没有一种安排适用于所有情况。
- **自测问题：** 根据原文，练习间隔应由什么因素决定？

这段示例文章支持五个彼此不同的知识点。若输入更短、可提取的独立知识点更少，Skill 会相应减少卡片数量。
